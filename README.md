# Deep Orange – a UCI chess engine written in Dyalog APL

> "The blunders are all there on the board, waiting to be made."\
> — Savielly Tartakower

## About

Deep Orange is a chess engine written in Dyalog APL.
It generates legal moves, searches for the best one and evaluates positions.
It was built test-first with its own small test framework.
The engine speaks the UCI protocol, so you can play it in any UCI-compatible chess GUI.
